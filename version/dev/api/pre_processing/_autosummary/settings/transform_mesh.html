transform_mesh#

class ansys.cfx.core.generated.pre_processing.settings_271.transform_mesh.transform_mesh(name: str | None = None, parent=None)#

Bases: Command

Transform the mesh. Various types of transformation are available: ‘Turbo Rotation’, ‘Rotation’, ‘Translation’, ‘Scale’, ‘Reflection’. The default values for unspecified arguments are the last values set for any mesh transformation. Refer to the CFX-Pre user documentation for a full description of all the settings.
